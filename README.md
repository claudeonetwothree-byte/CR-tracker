## Публикация (один раз, ~10 минут)

1. github.com → зарегистрируйтесь, если аккаунта нет.
2. **New repository** → имя, например `cr-tracker` → **Public** → **Create repository**.
3. На странице репозитория → **Add file** → **Upload files** → перетащите
   `index.html`, `data.enc.json`, `password.html` → **Commit changes**.
4. **Settings** → слева **Pages** → *Build and deployment*:
   Source = *Deploy from a branch*, Branch = `main`, папка `/ (root)` → **Save**.
5. Через 1–2 минуты обновите страницу Pages — там появится адрес вида
   `https://ваш-логин.github.io/cr-tracker/`. Это ссылка для сотрудников.

Репозиторий делайте **публичным**: приватный с Pages требует платного плана GitHub,
а смысла нет — там лежит только шифртекст. Поисковикам индексацию я запретил.

## Обновление данных после пятиминутки

Я присылаю новый `data.enc.json`. Вы: репозиторий → `data.enc.json` → **Add file**
→ **Upload files** → загрузить поверх → **Commit changes**. Через минуту страница свежая.
`index.html` при этом не меняется.

## Что умеет страница

- **Задачи** по срокам: просрочено, сегодня, до конца недели, больше недели,
  отложено, заблокировано. Горизонт считается в браузере при каждом открытии,
  поэтому «сегодня» — всегда сегодня, даже если данные я обновлял три дня назад.
- **Закрыто** — вся история по выбранному человеку, с отметкой «в срок»
  или «с опозданием N дн».
- **Проблемы** — канбан: поднято → в процессе → решено.
- Строка с именами сверху: выбрал себя — видишь только своё. По умолчанию «Все».
- Все разделы свёрнуты; как оставите, так и откроется в следующий раз.
- Отмечать выполнение нельзя — задачи закрываются на созвоне.

## Про доступ

- **Пароль общий.** Забрать его у одного уволившегося нельзя — только сменить
  для всех и разослать новый остальным. Это 30 секунд, но каждый раз.
- **Прошлое не стирается.** Кто уже заходил, мог сохранить или сфотографировать.
  Смена пароля закрывает доступ на будущее.
- **Аккаунты сотрудникам не нужны** — ни GitHub, ни Claude. Только ссылка и пароль.
